# Purify hub

Feedback and bug reports for **Purify**, a Diablo / survivors hybrid: https://purify-umber.vercel.app/

- Open an issue for a bug, a balance read or an idea.
- On the run end screen press **C** to copy your run as text, and paste it into the issue. It carries the seed, the class, every pick, the damage table and what killed you, which is what balance work needs.
- The game's source stays in a separate private repository; this repository holds only the tracker.
